# Screen and navigation flows

## Onboarding

Launch → tracking overview → voice overview → budgets/goals overview → privacy overview → choose currency, budget, theme, and reminder → Home.

Users can skip at any educational step. Setup choices remain editable in Settings.

## Add transaction

Home quick action, tab Add button, global `+`, or widget quick action → choose income/expense → amount → category → description → date → payment method → optional notes/tags/receipt → optional recurrence → validation → save → prior tab.

Opening an existing row uses the same form and adds duplicate/delete actions. Delete requires confirmation and exposes Undo.

## Voice entry

Microphone → Android speech recognizer → local parser extracts type, amount, category, description, date, and recurrence → review form → user completes any missing/ambiguous values → explicit Save.

Voice input never bypasses confirmation. Separate microphone controls can dictate descriptions and notes.

## Reports and history

Reports → choose Today/Week/Month/Year/All time → review income, expense, comparison, daily spending, category totals, average, and recurring count → export CSV or PDF through Android's document picker.

Income/Expenses → search → category filter → sort by time/amount/category → open transaction.

## Budgets and goals

Home or Settings → Budgets → view overall and custom progress → create category/custom budget → threshold color changes at 75% and 90%.

Home or Settings → Savings goals → create goal → add contribution → progress updates immediately.

## Widget

Launcher widget picker → Cyan Budget → resize as needed. Widget shows current balance, monthly budget progress, spending, quick-add, and voice actions. App privacy mode synchronizes masked values on the next widget refresh.
